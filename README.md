# Gym Log

Личный дневник тренировок: PWA без сборки, работает офлайн, данные на телефоне в IndexedDB,
завершённые тренировки уходят в Google Таблицу через Apps Script.

- Двойная прогрессия: только подсказки, вес сам не меняется.
- Без отказных подходов в рекомендациях для жима и свободного приседа; тяга прогрессирует только после отметки «спина ок».
- Офлайн-очередь с повторами, сервер идемпотентен по `workout_id`.
- RU/EN, системная тема, бэкап в JSON.

## Настройка
1. Разверни `apps-script/Code.gs` по инструкции в [apps-script/README.md](apps-script/README.md).
2. В приложении: Настройки → URL веб-приложения и общий секрет. Они хранятся только на устройстве.

## Разработка
`node dev/server.mjs` — приложение на :8765 и эмулятор Apps Script на :8766 (исполняет настоящий `Code.gs`).
При изменении файлов приложения подними `VERSION` в `sw.js`.
